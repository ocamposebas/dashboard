Estados protegidos

Qué ocurre cuando algo no sale perfecto.

No duplicar
label_ready

Etiqueta comprada y guardada. Imprimir o reimprimir no llama a purchase.

purchase_unknown

Hubo timeout o 5xx después de enviar. Se bloquea toda nueva compra y se busca por external shipment ID/rate ID.

failed

Rechazo definitivo 4xx. Se corrige dirección, saldo o carrier y se crea un nuevo intento explícito.

voided

Se pidió anulación; el reembolso depende de las reglas y tiempos del carrier.
